# Mon Budget — V1

Web app/PWA personnelle de suivi de budget.

## Fonctions incluses
- Tableau de bord mensuel
- Revenus et charges fixes
- Ajout / modification / suppression de dépenses
- Catégories
- Calcul du reste disponible
- Budget disponible par jour
- Épargne mensuelle
- Objectifs d'épargne
- Analyse par catégories
- Historique mensuel
- Export / import des données en JSON
- Installation sur iPhone comme une app
- Fonctionnement hors ligne après première ouverture

## Important
Les données sont stockées localement dans le navigateur de l'appareil.
Aucun compte bancaire n'est connecté.
Pense à exporter régulièrement une sauvegarde depuis Réglages.
